   → Or: python app.py

4. Test it:
   → Health: http://localhost:5000/api/health
   → Docs: http://localhost:5000/api/docs
   → Register: POST /api/auth/register

🔌 API ENDPOINTS AT A GLANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Authentication:
  POST   /api/auth/register          Register new user
  POST   /api/auth/verify-token      Verify Firebase token

Users:
  GET    /api/users/<uid>            Get profile
  PUT    /api/users/<uid>            Update profile
  GET    /api/users/<uid>/stats      Get statistics
  DELETE /api/users/<uid>/delete     Delete account

Habits:
  POST   /api/habits                 Create habit
  GET    /api/habits/<id>            Get habit details
  GET    /api/habits/user/<uid>      Get all user habits
  PUT    /api/habits/<id>            Update habit
  DELETE /api/habits/<id>            Delete habit
  POST   /api/habits/<id>/complete   Complete habit
  GET    /api/habits/<id>/streak     Get streak info

Plants:
  GET    /api/plants/<uid>           Get plant status
  GET    /api/plants/<uid>/health    Get health score
  PUT    /api/plants/<uid>/health    Update health
  POST   /api/plants/<uid>/decay-check  Check decay
  POST   /api/plants/batch-decay     Batch decay check
